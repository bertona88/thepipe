# A coupon atlas for geometry-first exploration

The central comparison is **same resin, comparable fabrication and conditioning, known objects, varied geometry**. It directly implements the user's preference to exploit out-of-the-box printed features before adding chemistry.

## Contact families

| Family | Role in the comparison | Main geometry variables |
| --- | --- | --- |
| Smooth or flat control | Establish native-surface reference behaviour | Patch size, edge geometry and measured finish |
| Sparse mesas | Reduce contact fraction with defined supports | Width, top radius, pitch and height |
| Ribs | Explore shear direction and progressive release | Direction, spacing, cross-section and edge radius |
| Cones or pyramidal features | Explore local contact and load concentration | Tip radius, angle, spacing and height |
| Inclined fibrils | Explore directional adhesive behaviour | Lean angle, slenderness, pitch and terminal geometry |
| Annular seal | Explore vacuum retention and detachment | Lip width, radius, compliance and aperture |
| Open grooves | Explore drainage or liquid exclusion | Cross-section, connectivity and orientation |
| Wicking geometry | Explore deliberate capillary uptake | Gap geometry, connectivity and reservoir relation |

The atlas is a set of useful families, not a mandatory all-at-once experiment. Fabrication throughput and inspection effort determine how many variations are practical.

## Useful outcomes

Measure pickup probability, retention during a specified motion/load, tangential holding force, pull-off response, release probability, final pose error and damage. Include angular placement error when orientation matters. Record wear or contamination changes with repeated use.

Differentiate outcomes such as part remaining on one jaw, part following the donor, receiver slip, rotational jump, residual wet bridge and successful retained release. A single aggregate success number can hide the mechanism.

## Conditions that make a comparison interpretable

Record normal preload, contact duration, approach and separation direction, speed, part material/geometry, RH, temperature and processing history. Repeat across enough specimens and cycles to distinguish a pattern from an unusually good print or first contact. Randomising comparison order can reduce drift and contamination-order bias.

A 200–500 µm nominal pad and 5–30 µm feature dimensions were conversational examples, not requirements. A contact pad must fit the actual part, and its features must remain geometrically distinct and mechanically appropriate. The [parameter register](../06-reference/parameter-register.md) retains the status of those numbers.

## Mechanical and fluidic companion specimens

A useful companion set can include flexures of varied geometry, tendon anchors, guide bends, channel cross-sections and channel-through-flexure sections. Each isolates a question that a complete arm might otherwise confound. These are evidence options, not a separate programme that must be completed before any assembly experiment.
