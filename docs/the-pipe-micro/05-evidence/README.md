# Evidence — how the concept becomes knowable

These documents describe useful evidence and its interpretation. They are not a milestone plan or a prerequisite list for allowing the concept to exist.

The main split is between topology and scale-dependent behaviour. A large printed model can expose tendon-routing mistakes and demonstrate cooperative motion. Actual small specimens are needed to learn the contact, flexure and environmental behaviour of the intended material/process.

| Evidence | What it can support | What it cannot establish by itself |
| --- | --- | --- |
| CAD | Nominal geometry and construction intent | Printed dimensions, material response or release reliability |
| Kinematic model | Reach, pose relationships and motion sequencing | Contact loads, adhesion or force margins |
| Deterministic dynamic/contact model | Behaviour under declared equations and parameters | Correctness of unmeasured material/contact assumptions |
| Macro printed demonstrator | Topology, routing, access and control logic | Microscale surface-force similarity |
| Micro coupon | Bounded material/contact behaviour in a specified setup | Full multi-arm machine performance |
| Observed integrated operation | Assembly behaviour for the tested conditions | Universal reliability outside that operating domain |

The best outcome is a coherent explanation: the geometry, environment, model and observation all describe the same specimen and operation. A failed release can be valuable evidence if its conditions and outcome are preserved.

[Macro and micro prototypes](macro-and-micro-prototypes.md) explains the two-scale concept. [The coupon atlas](coupon-atlas.md) organises contact and flexure variations. [Measurement and models](measurement-and-models.md) describes how results remain useful.
