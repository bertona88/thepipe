# Reference and traceability

This section keeps the atlas navigable as it grows. The [parameter register](parameter-register.md) collects reference scales and distinguishes them from requirements. [Open questions](open-questions.md) preserves decisions the discussion did not settle. The [discussion map](discussion-map.md) makes it easy to find where each major idea landed. [Sources and glossary](sources-and-glossary.md) separates the conversation, selected research precedents and terminology.

The concept was documented from the discussion supplied on 12 September 2026. The repository was not inspected or modified for this task. Statements about current repository branches, implemented interfaces or existing CAD qualification are therefore intentionally not used as design evidence here.

As the concept evolves, a useful change is one that makes a choice and its physical consequences clearer. New measured values should name their conditions. New ideas should be linked to the subsystem or operation they could improve. A previously open mechanism should only become a chosen design when that choice is actually made.
