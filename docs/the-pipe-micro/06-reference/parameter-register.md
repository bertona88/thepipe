## Units and coordinate conventions

Use mm for enclosure and arm packaging, µm for small features, N or µN for force, Pa or kPa for pressure, seconds for time, and % RH with temperature recorded for humidity. State radians or degrees explicitly for angles; s = rθ requires θ in radians. Mixed-unit arithmetic should convert to a consistent system before calculation.

The reference scales describe different functions. They should not be assembled into a dimensional drawing without resolving the shoulder radius, usable tool poses, camera geometry and support structure.
