# Physics — small bodies, consequential interfaces

The architectural appeal of shrinking the distal mechanism comes from how geometry changes mass, inertia, stiffness and the balance of forces. The difficulty comes from the same scale change: contact and environment can matter more relative to weight.

The discussion's six concerns are closely coupled:

| Concern | Where it enters the operation |
| --- | --- |
| Electrostatic adhesion | Approach, unintended attraction, rotation and residual attachment |
| Contamination | Changes to every subsequent contact, including optical appearance |
| van der Waals adhesion | Close-contact retention and pull-off |
| Capillary effects | Accidental or intentional liquid bridges |
| Reliable release | Transfer between supporting interfaces |
| Polymer stiction | Persistent attachment or resistance to starting motion from several combined mechanisms |

The design response is a combination of contact geometry, environment control and cooperative motion. No single native polymer property solves the whole interface.

[Scaling](scaling.md) provides idealised comparisons with assumptions attached. [Contact and adhesion](contact-and-adhesion.md) explains how the mechanisms interact. [Release and retention](release-and-retention.md) translates them into useful manipulation behaviour.
