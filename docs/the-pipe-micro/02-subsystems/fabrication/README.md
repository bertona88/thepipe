# Fabrication — use resolution where function needs it

**Chosen direction:** printed macro prototypes support mechanism development; microSLA and 2PP support small structures, with 2PP especially interesting for intricate contact and compliant geometry.

2PP provides a way to write three-dimensional polymer structures at small feature scales. Its practical value here is geometric freedom: thin compliant regions beside stiffer links, structured contacts, accessible channels, markers and assembly features. A published feature demonstration elsewhere does not guarantee the same feature survives this resin, build orientation and loading.

## Selective use of fine fabrication

The entire optical enclosure does not need 2PP. Macro printing can make supports, cassettes and enlarged mechanisms. MicroSLA may be useful for geometries its selected process can resolve. 2PP can be reserved for the distal features whose function depends on finer shape control.

A 10–15 mm reach need not imply a solid 15 mm 2PP print. Sparse structures, mixed fabrication scales and later assembled structures are possible. Build volume, writing time, stitching, cleaning access and specimen handling are process-selection questions, not fixed capabilities claimed by this atlas.

## One resin first

The first printed arm and contact family should use one known resin, a recorded print/cure condition and native surfaces. Stiffness differences can come from section geometry. The purpose is to understand what geometry alone achieves and preserve a clean comparison between contact designs.

Coatings, fluorination, conductive treatments and multiple materials remain later options. Their absence is not a claim that native methacrylate has ideal surface behaviour.

## Complete fabrication includes release and cleaning

A geometry is only useful if uncured material can be removed, thin features survive processing, channels can be cleared, and the finished structure can be mounted and tensioned. Dimensional compensation can be treated routinely where appropriate, consistent with the user's view that shrinkage should not dominate this direction.

The [materials and process document](materials-and-process.md) defines what needs to remain attached to a specimen's identity. The [two-scale prototype document](../../05-evidence/macro-and-micro-prototypes.md) explains how macro and micro evidence complement each other.
