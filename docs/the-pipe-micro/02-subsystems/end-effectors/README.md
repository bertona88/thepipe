# End effectors — interfaces with selectable behaviour

A tool is useful when its attachment can be established, maintained and deliberately reduced. The most interesting 2PP freedom is the ability to design those behaviours into contact geometry.

| Tool family | Establishes retention through | Candidate release action |
| --- | --- | --- |
| Compliant tweezer | Normal loading, friction and possible form constraint | Asymmetric opening, peel, receiving support or ejector |
| Sparse-contact tip | Controlled contact geometry with limited real area | Progressive separation into a supported destination |
| Directional adhesive pad | Loading direction and compliant microstructure | Change shear direction or peel angle |
| Vacuum tip | Pressure difference over an effective sealed area | Vent, detach seal and verify separation |
| Capillary tool | Deliberately formed liquid bridge | Change wetting/contact configuration or transfer to a receiver |
| Support or locating tool | Geometric seating and constraint | Remove load after another interface supports the object |

The first machine can use a native-resin mechanical gripper. This does not make the other families peripheral: the platform is valuable partly because the same observed manipulation space can host different attachment physics.

## Tool and part are a pair

The material, finish and geometry of the object matter as much as the tip. A smooth transparent gear, a textured handling tab and a rough printed coupon are different interfaces even at the same outer size. Some parts can be designed for handling; others must be manipulated on their existing surfaces.

## Holding and leaving are separate achievements

A tool may have excellent pickup probability yet poor release placement. Another may release readily but slip during orientation. Useful comparison therefore includes load capacity, pickup probability, retention under disturbances, release probability and final pose error.
