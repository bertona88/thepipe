# Vision — a tiny cooperative workshop

The interesting thing about The Pipe is that the whole working volume can be a robot. A manipulator does not need to carry every capability on its own. It can share observation, cooperate with neighbouring arms, use the destination as a fixture and return to a tool station when a different contact behaviour is useful.

The cylindrical idea began with the image of an O'Neill cylinder: a surrounding surface from which things can approach a common interior. That image remains useful as an organisational principle. It offers many approach directions and a shared longitudinal coordinate. It does not require the enclosure to rotate, artificial gravity, or a particular rail construction.

## Tiny hands change the centre of the problem

With smaller distal mechanisms, less structure needs to occupy the optical scene. Flexures can replace assembled joints in candidate arm topologies. Tendons can bring energy from accessible external actuators. The printed structure can combine a link, spring, fingertip, marker and channel in a single spatial design.

The central challenge then becomes managing the interface between an object and everything touching it. Friction, adhesion, moisture, charge, compliance and geometry influence whether a gear can be acquired, held, aligned and left behind. That interface is a design opportunity. 2PP can make deliberately sparse contacts, directional fibrils, peel edges, sealing ridges, wicks and locating structures.

## Cooperation is a mechanical capability

An arm can act as a temporary fixture for another. One can hold a component while a second changes its grip; a third can stabilise the assembly. The destination can deliberately supply retention. A receiver can establish support before a donor withdraws. These behaviours make reliable release part of the machine's purpose.

The aspiration is a family of mobile microtools: some general, some specialised, all operating in a shared observed space. A successful first machine could later assemble more capable tools and arms from different materials.

## What keeps the spirit intact

Preserve the asymmetry between generous infrastructure and tiny interaction mechanisms. Preserve the freedom to print geometry that would be unreasonable to machine or assemble conventionally. Preserve the role of other arms in an operation. Preserve direct observation of what really happened.
