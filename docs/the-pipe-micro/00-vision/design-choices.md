# Chosen direction and remaining freedom

The choices below capture the latest preferences in the supplied discussion. The baseline is a conceptual starting configuration, not a completed machine specification.

| Topic | Present direction | What remains free |
| --- | --- | --- |
| Objects | Begin in the 300 µm–1 mm range | Exact benchmark shapes, clearances and material pairs |
| Reference object | Approximately 500 µm is useful for reasoning | It is not a requirement that every part be that size |
| Distal mechanism | Small printed flexure arms; 10–15 mm was discussed | Joint count, topology, link dimensions, travel and strain limits |
| Optics | Keep useful external scale and baseline | Camera count, lenses, illumination, windows and placement |
| Enclosure | A controlled cylindrical assembly chamber | Exact diameter, length and internal support geometry |
| Base motion | Preserve longitudinal z and circumferential θ positioning | Separate carriages, shared stages, shoes, rings, cables or other implementations |
| Actuation | Motors outside; tendons transmit motion | Tendon material, count, attachment, guides and sensing |
| Distal materials | Prefer no metal inside the manipulation volume | Whether later evidence motivates a local exception |
| First printed arm | One structural resin and native surface | Geometry can vary across stiff and compliant regions |
| Contact engineering | Texture and shape first | Smooth pads remain controls and possible adhesive tools |
| Coatings | Fluorination and other treatments are interesting later | No coating is needed to define the first concept |
| Release | Other arms, fixtures and deliberate interface changes | Peel, ejectors, venting, directional loading and other methods |
| Fluidics | Keep printed channels and external vacuum in the design space | Whether the first working tool needs fluidics at all |
| Environment | Sealed chamber with small part/tool transfer chambers | Filtration, flow geometry and conditioning arrangements |
| Humidity | Control RH and preserve humidity cycles as an idea | Material-specific steady conditions and cycle recipes require evidence |
| Fabrication | Macro printed demonstrators plus microSLA/2PP specimens | Which process makes each feature economically and reliably |
| Shrinkage | Treat ordinary dimensional compensation as manageable | Record actual geometry where it affects function; no separate shrinkage programme is assumed |
| Future manufacture | A working machine may assemble later arms from different materials | Joining, handling and verification methods |

“Single material” applies to the initial printed arm/gripper structure. It does not require purchased tendons, external tubing, camera optics or the enclosure to be made from that resin. “Metal-free” is strongest near the manipulation region; external motors and instrumentation can contain metal.

## Assistant elaborations introduced in this atlas

Several details below make the concept coherent without claiming they were settled in conversation: distinguishing enclosure radius from shoulder radius; treating tendon and hose forces as base loads; requiring observed donor separation before calling handoff complete; and comparing patterned tool surfaces against a smooth control under the same conditions. These are engineering elaborations, not new user commitments.

No exact rail, humidity percentage, tendon diameter, force limit or texture pitch has been selected. Numerical examples are collected in the [parameter register](../06-reference/parameter-register.md), where their status stays visible.
